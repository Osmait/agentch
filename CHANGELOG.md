# Changelog

All notable changes to Agentch. Versions follow [Semantic Versioning](https://semver.org).
Add a section for a version before releasing it; it becomes the summary of the release notes.

## [0.1.1]

- App icon: the notch with three usage bars.

## [0.1.0]

First release.

- Hover over the notch to see usage limits for Claude Code, Codex, Cursor, GitHub Copilot, Grok, Muse Code, OpenCode Go and Antigravity.
- 5-hour, weekly and monthly windows, with when each one resets.
- Reads the logins you already have on your Mac; no account and no servers.
- Settings with themes, opacity and blur, and a switch per subscription.
